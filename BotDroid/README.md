# BOT DROID

Autorrespuestas naturales para WhatsApp / WhatsApp Business usando solo notificaciones autorizadas.

## Obtener el APK (sin instalar nada)
1. Crea un repositorio en GitHub y sube todo el contenido de esta carpeta.
2. Ve a la pestaña **Actions** → "Build APK" → espera ~5 min.
3. Descarga el artefacto **BotDroid-APK** (contiene app-debug.apk) e instálalo.

## Obtener el APK con Android Studio
Abre la carpeta → Build → Build APK(s).

## Primer uso
1. Abre la app → "Dar acceso a notificaciones" → activa BOT DROID.
   (Android 13+: Ajustes → Apps → BOT DROID → ⋮ → "Permitir ajustes restringidos".)
2. Elige la personalidad (Amigable / Natural / Profesional / Comercial).
3. Prueba mensajes en la sección "Probar", edita tus reglas y activa la automatización.

La regla de Pagos viene desactivada: configúrala con tus opciones reales antes de activarla.
